## Key Findings

### Root Cause Analysis: Why Data is Empty

**Problem**: The `backend/data/vector_db/` folder exists but is completely empty despite indexing logic.

**Root Causes Identified**:

1. **Cause #1: Function Not Executed**
   - `index_website_data()` is only called when `main.py` is run directly
   - If `main.py` has never been executed, no data would be saved
   - Status: LIKELY

2. **Cause #2: Relative Path Resolution Issue** ⚠️ CRITICAL
   - Current path: `VECTOR_DB_PATH = "backend/data/vector_db"`
   - This is relative to the current working directory
   - If script runs from different directory, path won't resolve
   - ChromaDB would either fail silently or create files in wrong location
   - Status: HIGH PROBABILITY

3. **Cause #3: API Key Missing/Invalid**
   - If GOOGLE_API_KEY is not in .env or is invalid
   - GoogleGenerativeAIEmbeddings initialization would fail
   - Indexing would abort without persisting data
   - Status: POSSIBLE

---

## Recommended Solutions

### Solution 1: Fix Relative Path (RECOMMENDED) 🔧
**File**: `core/config.py`

**Change from**:
```python
VECTOR_DB_PATH = "backend/data/vector_db"
```

**Change to**:
```python
from pathlib import Path
VECTOR_DB_PATH = str(Path(__file__).parent.parent / "data" / "vector_db")
```

**Benefits**:
- Works from any working directory
- Uses absolute path resolution
- Portable and robust
- Industry standard practice
